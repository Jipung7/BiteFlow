# Panduan Memasang Ekstensi BiteFlow di Browser

Ekstensi BiteFlow dapat langsung dipasang di Google Chrome, Microsoft Edge, Brave, atau browser berbasis Chromium lainnya melalui mode pengembang lokal.

---

## Prosedur Instalasi

1. **Buka Halaman Ekstensi Browser:**
   - Google Chrome: Akses `chrome://extensions` pada bilah alamat.
   - Microsoft Edge: Akses `edge://extensions` pada bilah alamat.

2. **Aktifkan Developer Mode:**
   - Di sudut kanan atas jendela ekstensi, aktifkan sakelar **Developer mode** (Mode Pengembang).

3. **Muat Paket Ekstensi:**
   - Klik tombol **Load unpacked** (Muat yang belum dibongkar) di bilah navigasi atas.
   - Pilih direktori:
     `c:\Users\MyBook Hype AMD\Documents\Project\Antigravity\App idea\AppIdea1\extension`
   - Klik **Select Folder**.

---

## Verifikasi Pemasangan

Setelah dimuat:
- Ikon BiteFlow akan muncul di bilah alat browser.
- Klik ikon BiteFlow untuk membuka pop-up status dan kontrol.
- Klik **Mulai Rekam Layar** untuk memulai perekaman tab.
- Indikator perekaman mengambang akan tampil pada halaman aktif dan menangkap koordinat interaksi klik secara otomatis.
- Klik **Selesai** untuk membuka antarmuka editor dan pemutar panduan.
